7. Empresa de mantenimiento
Una empresa recibe solicitudes de mantenimiento de diferentes clientes.
Cada solicitud tiene ubicación, problema, técnico solicitado y prioridad.
Las solicitudes esperan hasta que un técnico esté disponible.
Durante el proceso pueden aparecer cambios de prioridad o cancelaciones.
